# 技术分享：JavaScript 异步编程

在现代 JavaScript 开发中，异步编程是一个核心概念。本文将介绍几种常见的异步编程模式。

## 回调函数 (Callbacks)

最传统的异步处理方式：

```javascript
function fetchData(callback) {
    setTimeout(() => {
        const data = { id: 1, name: 'John' };
        callback(null, data);
    }, 1000);
}

fetchData((error, data) => {
    if (error) {
        console.error('Error:', error);
    } else {
        console.log('Data:', data);
    }
});
```

## Promise

Promise 提供了更好的错误处理和链式调用：

```javascript
function fetchUser(id) {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            if (id > 0) {
                resolve({ id, name: `User ${id}` });
            } else {
                reject(new Error('Invalid user ID'));
            }
        }, 1000);
    });
}

fetchUser(1)
    .then(user => {
        console.log('User:', user);
        return fetchUser(2);
    })
    .then(user => {
        console.log('Another user:', user);
    })
    .catch(error => {
        console.error('Error:', error.message);
    });
```

## 并行异步操作

当需要同时执行多个异步操作时：

```javascript
async function fetchMultipleUsers() {
    try {
        // 并行执行多个异步操作
        const [user1, user2, user3] = await Promise.all([
            fetchUser(1),
            fetchUser(2),
            fetchUser(3)
        ]);
        
        return [user1, user2, user3];
    } catch (error) {
        console.error('Error fetching users:', error);
        throw error;
    }
}
```

## 最佳实践

1. **使用 async/await**：相比于 Promise 链，async/await 代码更容易阅读和调试
2. **适当的错误处理**：始终使用 try/catch 或 .catch() 处理可能的错误
3. **避免回调地狱**：尽量避免深层嵌套的回调函数
4. **并行执行**：当操作之间没有依赖关系时，使用 Promise.all() 并行执行

## 结论

异步编程是 JavaScript 的重要特性，掌握这些模式能让你写出更高效、更可维护的代码。从回调函数到 async/await，每种方式都有其适用场景，选择合适的工具来解决具体问题。
